- Link count after each rm: Before deleting any file, all three hard links (one.txt, two.txt, three.txt) showed a link count of 3. After rm -- one.txt, the remaining names (two.txt, three.txt) showed a link count of 2. After rm -- two.txt, the remaining name (three.txt) showed a link count of 1.
- Is the data gone after deleting one.txt? No. cat two.txt still printed "keep me" because two.txt and three.txt still pointed to the same inode. The data is only removed from disk when the last hard link (three.txt) is deleted so the link count drops to 0 (and no running program still has the file open).
